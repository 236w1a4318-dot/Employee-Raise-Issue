# Employee Raise Issue

## About the Project

Employee Raise Issue is a custom ServiceNow application developed to manage employee salary raise requests. It provides a simple and user-friendly way for employees to submit their raise requests through the Service Portal.

The application stores employee raise request details in a custom table and provides the required fields and form configurations to manage the requests. UI Policies are used to control the form behavior and field dependencies.

A Record Producer is created to make the request submission process easier for employees. The Service Portal provides a simple interface where employees can access and submit their raise requests.

Custom widgets are also used to improve the Service Portal experience and display the required information to users.

The complete application is tested to make sure that the forms, fields, Record Producer, Service Portal, and widgets work correctly.

## Key Features

- Custom ServiceNow application
- Employee raise request form
- Custom table and fields
- UI Policies and field dependencies
- Record Producer for submitting requests
- Service Portal for employees
- Custom Service Portal widgets
- Request tracking
- Testing and validation

## Project Objective

The main objective of this project is to provide a simple and organized process for employees to submit and manage their raise requests using ServiceNow.
